Mixture of Experts с гарантированной стойкостью

Каждый токен обрабатывается одним из 20 экспертов (4 полосы контекста × 5 алгебраических классов). Все классы биективны по построению: SUB (AES S-box + key-affine), GF (умножение в GF(2⁸) с неприводимым полиномом), ARX (add-rotate-xor + S-box), TRI (унитреугольная матрица + S-box), Feistel (3-раундовая сеть Фейстеля с S-box). Дилатация голов обеспечивает полный охват префикса за один слой. Лестница внутри токена — два прохода унитреугольного смешивания. det = 1 для всей сети.

все биективны · DP ≤ 4/256 · NL ≥ 112

Каждый класс — независимая алгебраическая структура. SUB использует AES S-box, GF — умножение в поле Галуа с неприводимым полиномом, ARX — сложение-поворот-XOR с финальным S-box, TRI — унитреугольная матрица с S-box на каждом канале, Feistel — 3-раундовая сеть Фейстеля с S-box.

Обратимость доказана конструктивно: все 5 классов биективны, обновление не читает обновляемый байт, диагональ единичная. Дифференциальная равномерность ≤ 4/256 для каждого класса, нелинейность ≥ 112. Дальнодействие обеспечено дилатацией голов. Объём не ограничен архитектурой. Криптостойкость композиции не доказана: требуется анализ MEDP всей схемы. Сырой режим утекает равенство сообщений; для семантической безопасности и целостности есть режим nonce + HMAC. Не является стандартом.
